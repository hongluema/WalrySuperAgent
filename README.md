## 错题记录

和grok 每次修agent问题，修复几轮之后，可以要求记录下，这样说：

```
把咱俩今天的对话，修复agent和前端问题的日志总结记录下，放到walrySuperAgent 的Error.md 中，格式是：

错误【index】:
【时间】：xxx
【问题描述】：xxx
【错误原因分析】：xxxx
【解决思路】：xxxx
【解决办法】：xxxx

不用写改动的代码，只需要写思路，都是总结的，切记：写之前，先查看下的Error.md，之前记录过的不要在记录了，只记录新的
```
